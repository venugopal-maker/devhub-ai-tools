# devhub-ai-tools

DevHub

AI tools for developers, all in one place.

DevHub is a one-page website that lists 69 AI tools for coders, frontend developers and database developers. Every tool shows if it is free.

What you get
Code assistants, app builders, frontend tools, databases, models and APIs, code review and deployment platforms
Search box and 8 category buttons
Price badge on every card: Free, Free tier, Open source, Trial or Paid
Tool logos and category icons
Works on phones, tablets and laptops
Files
File	What it does
index.html	The whole DevHub website. The design and the code are inside this one file.
README.md	This guide.

No install and no build steps are needed.

Run DevHub
Download index.html.
Open it in your browser (double-click it).
Search for a tool or pick a category.
Add or edit a tool
Open index.html in a text editor.
Find the list that starts with var T=[.
Add one line:
js
["Tool name","https://tool-website.com","Category","Short description","Free tier"],
Use one of the existing categories. A new category also needs a color in the COL list and an icon in the ICO list in the code.
The last value is the price badge: Free, Free tier, Open source, Trial or Paid.
Save the file and refresh the browser.
Put DevHub online for free

Upload index.html (keep this exact name) to one of these:

GitHub Pages: create a repository, upload the file, then turn on Pages in Settings.
Netlify: drag and drop the file at app.netlify.com/drop.
Cloudflare Pages or Neocities: upload it in their dashboard.
Notes
Logos load from Google's favicon service, so they need an internet connection. If a logo cannot load, the card shows a colored letter.
Free plans and limits change often. Check each tool's pricing page before relying on it.
Tool names and logos belong to their owners.
